# Changelog

## 1.0.0 — 2026-11-20

- Rebuilt the WordPress publishing workspace, including the dashboard, provider catalog, recipe editor, field mapping, job details, filters, and post preview.
- Added Facebook Pages, Instagram, LinkedIn, Threads, Mastodon, Bluesky, Pinterest, X, Tumblr, and Reddit.
- Added manual WhatsApp Channel publication with message copying and recorded confirmation.
- Added staged Instagram image preparation, featured-image snapshots, provider-specific validation, and rate-limit scheduling.

## 0.1.0 — 2026-10-01

- Added the first secure publishing slice: WordPress content normalization, bounded rules with traces, recipes, encrypted destinations, signed webhooks, Telegram text, and asynchronous jobs.
- Added pause/staging controls, post exclusion, intake cap, manual queue, operational admin screens, focused tests, CI checks, and packaging.
- Documented unsupported parts of the broader omnichannel vision.
